# Privacy Policy

Last updated: April 29, 2026

Qibla AR Finder membantu pengguna menemukan arah kiblat melalui lokasi perangkat, sensor kompas, dan kamera untuk mode AR overlay.

## Information We Use

### Location

- Aplikasi meminta akses lokasi untuk menghitung arah kiblat dan jadwal salat sesuai posisi pengguna.
- Lokasi diproses di perangkat untuk pengalaman aplikasi.
- Lokasi terakhir dapat disimpan secara lokal di perangkat agar aplikasi tetap berguna saat offline.

### Camera

- Aplikasi meminta akses kamera hanya untuk menampilkan camera overlay pada mode AR.
- Gambar kamera dipakai secara langsung di perangkat dan tidak diunggah oleh aplikasi.

### Sensor Data

- Aplikasi menggunakan sensor kompas perangkat untuk membaca heading/arah hadap.
- Data sensor dipakai secara real time di perangkat dan tidak dikirim ke server.

## Data Storage

- Aplikasi menyimpan cache lokasi terakhir dan cache jadwal salat secara lokal di perangkat.
- Aplikasi ini tidak memerlukan akun pengguna.
- Aplikasi ini tidak memiliki backend aktif untuk mengumpulkan data pribadi pengguna.

## Data Sharing

- Aplikasi tidak menjual data pribadi pengguna.
- Aplikasi tidak membagikan lokasi, kamera, atau data sensor ke pihak ketiga untuk iklan.

## Security

- Data cache aplikasi tersimpan secara lokal di perangkat.
- Pengguna dapat menghapus data aplikasi melalui pengaturan Android untuk menghapus cache lokal.

## Children's Privacy

Qibla AR Finder tidak dirancang khusus untuk anak-anak, namun juga tidak dengan sengaja mengumpulkan data pribadi anak melalui server aplikasi.

## Changes to This Policy

Privacy Policy ini dapat diperbarui dari waktu ke waktu untuk menyesuaikan perubahan fitur atau kewajiban distribusi aplikasi.

## Contact

Jika kamu ingin menerbitkan aplikasi ini ke store, sebaiknya tambahkan email kontak resmi pengembang sebelum privacy policy dipublikasikan.
